# Certifiable Search and Neutralization of Radio Emitters with Unknown Directionality

Reference implementation, discrete-event simulator, experiment scripts and generated data for the
paper:

> **Certifiable Search and Neutralization of Radio Emitters with Unknown Directionality Using a
> Bearing-Only Mobile Sensor**
> Changxuan Cao, Zexu Ouyang — East China University of Technology, Nanchang, Jiangxi, China
> *(submitted to Robotics and Autonomous Systems)

**Code and data:** <https://github.com/ccx111145/certifiable-emitter-search>*

---

## What the problem is

A single mobile platform carrying a direction finder must locate and neutralize an unknown number of
radio-frequency emitters in a bounded region, using only noisy bearings, and must additionally be
able to **certify that no emitter has been missed**.

Three properties make this hard:

1. the number of emitters is unknown, so the mission cannot stop on a counter — it must stop on a
   *proof*;
2. each emitter has an unknown effective reception radius;
3. an emitter may radiate only into a half-plane whose orientation is unknown, so **the absence of a
   signal carries no information about distance** — classical coverage reasoning ("the platform has
   been everywhere, therefore nothing is left") is unsound.

## What the code does

* **Detectability condition.** A measurement network detects an emitter of arbitrary orientation
  **iff** `G ∈ conv(S_G)`, where `S_G` is the set of network points within the worst-case reception
  radius of `G`. A corollary is that the network must extend *outside* the region of interest.
* **Certifiable search.** Every channel is driven to one of two terminal states — *cleared* or
  *certified absent* — so termination is decidable rather than a timeout.
* **Network design.** The census network is a covering-salesman problem under the enclosure
  constraint; a two-layer construction (dense inner lattice + a ring just outside the region) needs
  25 points and a route 42 % shorter than the natural single-layer lattice.
* **Non-ideal channels.** A `q`-relaxed evidence set removes the false absence certificates that
  spatially scattered multipath produces; sound *and complete* certification under `q` outliers
  additionally requires a detection redundancy `r > q`, which covering networks do not attain.

## Quick start

```bash
python -m pip install -r requirements.txt

python dev/selfcheck.py          # 51 assertions covering the whole pipeline (~ minutes)
python dev/final_check.py        # manuscript consistency: citations, labels, environments
```

Every number in the paper is regenerated by `dev/selfcheck.py`. Individual experiments:

```bash
python exp/compare.py              # baseline comparison (Table 2, Fig. 2)
python exp/ablation.py             # ablation (Table 4)
python exp/planning.py             # planning isolation (Table 3)
python exp/rf_chain.py             # direction-finding chain error statistics (Table 5)
python exp/rf_end2end.py           # end-to-end runs with the array chain (Table 6)
python exp/nonconvex_consistent.py # obstructed workspace (Table 8 and §6.11)
python exp/reliability.py          # certificate reliability map (Tables 12-13, Fig. 5)
python exp/fig_vector.py           # regenerate the vector figures
```

## Where the guarantee stops

The paper reports its own negative results rather than leaving them to the reader:

1. **Bounded bearing error.** The outer approximation is sound only if the true angular error stays
   within `δ`. Over-estimating `δ` eightfold costs under 1.5 % in the directional scenario, so the
   safe direction is cheap.
2. **Multipath.** A 2 % spurious-bearing rate produces false absence certificates under the hard
   outer approximation; the `q`-relaxed intersection removes them, but sound *and complete*
   certification then requires a detection redundancy `r > q` that the covering networks here do not
   possess. **Stated as an open network-design problem.**
3. **Antenna aperture, not SNR.** With realistic patterns the ideal half-plane is *not* the worst
   case: a narrow main lobe with low sidelobes can point between network points and collapse the
   guaranteed fraction from 1.000 to 0.004.
4. **Coherent ghost (open).** A fixed reflector creates a spatially correlated error that the
   `q`-relaxed framework handles structurally poorly.

The study is **simulation-only**; no hardware validation was performed. The direction-finding chain
is benchmarked against the Cramér–Rao bound as an external consistency check.

Python 3.9+. **NumPy and Matplotlib are the only dependencies** — no SciPy, no compiled extensions,
